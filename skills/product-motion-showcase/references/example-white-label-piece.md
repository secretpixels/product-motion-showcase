# Example: a white-label design system piece

One finished interface video, shown so you can see how the building blocks fit together. Do not copy its content. Use the logic.

25 seconds, 4:3 (1600x1200), 30 fps, looping.

1. **Open on real screens.** Screen recordings of an app.
2. **System reveal.** Design tokens grow out of the app as drawn lines. Each line carries a pill with a token name.
3. **Brand switch.** The lines flow into a theme switch. The switch flips from brand A to brand B.
4. **Same system, new brand.** The lines continue into the app of brand B. Same names, different values.
5. **Object moment.** The 3D object from both apps (vehicles in this case) turns into a dancing grid.
6. **Logo close.** The logos close the piece and the video loops to the first frame.

Why it works:

- One idea: one system, two brands.
- Real product first, system second, re-theming third.
- Every move overlaps with the next, so the piece feels like one gesture.
- The music sets the bars, so every transition lands on a beat.
- The end joins the start, so it can run on repeat.

Timing numbers for this piece: 134.4 BPM x 14 bars = 25 seconds.
